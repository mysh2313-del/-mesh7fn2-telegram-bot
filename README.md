# Mesh7fn2 Telegram Bot — Starter

هذه نسخة تأسيسية آمنة لتشغيل البوت وربطه بحسابك. لا تحتوي بعد على مصدر بيانات لسلاسل الخيارات، لذلك لا تصدر أسعارًا أو توصيات تداول.

## 1) ارفع الملفات إلى GitHub
1. أنشئ مستودعًا جديدًا (Repository) باسم `mesh7fn2-telegram-bot`.
2. ارفع `main.py` و`requirements.txt` و`Procfile`.

## 2) انشره على Railway
1. افتح https://railway.app وسجّل الدخول.
2. اختر New Project ثم Deploy from GitHub Repo.
3. اختر المستودع الذي أنشأته.
4. من Variables أضف متغيرًا اسمه `BOT_TOKEN` وضع قيمة التوكن فيه.
   - لا تضع التوكن داخل الملفات أو GitHub.
   - لا تشاركه مع أي شخص.
5. شغّل الخدمة وتأكد أن حالة النشر أصبحت Active.

## 3) اختبر البوت
افتح https://t.me/Mesh7fn2_bot واضغط Start، ثم أرسل `/status`.

## ملاحظات
- هذه النسخة لا تتصل بحساب دراية ولا تنفذ صفقات.
- قبل تفعيل تنبيهات CALL/PUT يلزم ربط مزود بيانات موثوق وحديث لسلسلة الخيارات، مع أسعار العرض والطلب وتاريخ الانتهاء والسيولة.
- إذا سبق أن أرسلت التوكن لأي شخص أو نشرته في مكان عام، ألغِه من BotFather وأنشئ توكنًا جديدًا.
